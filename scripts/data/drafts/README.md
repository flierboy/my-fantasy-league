# Draft board CSV imports

Place CSV files here for reference (optional). Primary import path is
**Admin → Drafts → Bulk import CSV**.

## CSV format

```
round,pick_in_round,overall_pick,player_name,position,nfl_team,fantasy_owner_name
1,1,1,Justin Jefferson,WR,MIN,THICKY LEN
1,2,2,Christian McCaffrey,RB,SF,yo mama
```

Owner matching is fuzzy (e.g. THICKY LEN / Leonidas Len → Len, HAMIE → HAM BONE).
